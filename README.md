# 🐱 Floppa AI

> A chatbot that talks like Floppa. Big ears, bigger vibes.

**Floppa AI** is a Python chatbot built by [Glungus Corporation](#) that responds to your messages in the one and only Floppa personality — chill, chaotic, and always a little bit unhinged. Talk to it, and it talks back like everyone's favorite caracal meme cat.

---

## ✨ Features

- **Floppa personality** — every reply is in-character (bingus-approved)
- **Chat loop** — type a message, get a Floppa response, repeat
- **Easy to customize** — swap in your own replies, moods, and catchphrases
- **Pure Python** — no complicated setup, just run and chat

---

## 🚀 Getting Started

### Requirements

- Python 3.10 or newer

### Installation

```bash
# 1. Grab the code
git clone https://github.com/glungus-corp/floppa-ai.git
cd floppa-ai

# 2. (Optional) install any extras
pip install -r requirements.txt
```

### Run it

```bash
python floppa_ai.py
```

Then just start typing!

## 🛠️ How It Works

Floppa AI reads what you type, picks a response that fits the Floppa mood, and prints it back. You can teach it new lines by editing the responses in `floppa_ai.py`:

```python
responses = {
    "hi":  "huh. oh. hello. i was napping on the keyboard.",
    "bye": "leaving already? ok. i will be here. being floppa.",
    # add your own here 👇
}
```

Add as many as you want — the more Floppa, the better.
